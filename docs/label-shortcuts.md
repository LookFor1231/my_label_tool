# 标签快捷键与画布提示

## 使用方法

- 在设置中分别调整操作提示和标签提示条数（1–50），窗口较小时自动进一步减少。
  当前标签始终占一个名额，未绑定快捷键也会显示；省略项会显示数量。
- 每个快捷键动作都有「在画布提示中显示」开关，固定动作也可设置。撤销、重做、
  保存默认隐藏，快捷键照常生效。恢复提示显示默认值不改变实际键位。
- 提示只在遮挡鼠标附近操作区域时上下避让；两端均遮挡时整体透明，离开后延迟
  200ms 恢复。移动后保留位置，避免自动来回跳动。减少动态效果时无需动画即可工作。
- 点击侧栏「选择标签与样例图」或按 F2（可在设置改绑）打开标签选择面板。
  输入名称、用上下键移动候选、Enter 确认；Esc 或再次按打开键取消。
  当前有选中标注时，确认会修改该标注标签，可用 Ctrl+Z 撤销；不兼容标签不能确认。
- 管理模板和标签时点击快捷键框，先按修饰键再按字母/数字录制；按 Backspace、
  Delete 或旁边的清除按钮取消绑定，保存标签/模板后持久化。组合键不作为默认绑定。

提示偏好只保存在本机显示设置，不进入项目或标签。选择面板按可见行读取项目
`icon/` 样例图；缺失目录或单张图片失败不阻止标签选择。

## 组合键设计记录（2026-10-21）

标签绑定继续存放在 `LabelConfig.shortcut`，跟随标签模板、项目标签快照及原生 JSON
往返，不建立按标签 ID 索引的第二套绑定表。Rust 对应字段仍为 `Option<String>`。
旧项目缺少字段时保持未绑定；旧单字母或数字保持可用，保存时使用小写。
新增格式为按 `Ctrl+Alt+Shift+` 固定顺序排列的可选修饰键，加一个小写字母或数字。
例如 `a`、`Ctrl+a`、`Alt+1`、`Shift+1`、`Ctrl+Shift+a`，不支持两个普通键。
先按修饰键，再按普通键；匹配使用本次键盘事件，不缓存修饰键状态。

### 插件边界

插件 `label-preset` v1 的输入及 `exporter` v1 的输出标签继续遵守
`^[a-z0-9]$`，不扩大两个插件 Schema，不更改 Rust 插件校验。
宿主在唯一的 `runPluginExport` 前端命令封装中构建独立的 v1 标签投影：保留所有
标注与标签业务字段，合法单键原样传递；组合键或非法历史绑定不传 `shortcut`。
此字段本来就是可选的编辑偏好，省略不影响标注的含义；不得改写项目中的原始标签。
插件输出文件不承诺保存宿主组合键，项目文件和原生 JSON 才是完整往返载体。
插件预置仍只能提供单键；用户将预置复制为可编辑模板或项目标签后可设置组合键。

无插件对外契约变更：宿主 API 整体、exporter、prelabel、NDJSON 协议与 manifest
schemaVersion 全部保持 1，无弃用或移除。现有 ADR 0003–0007 不变。

### 冲突与加载

所有标签及固定、可改绑动作共用 `detectConflicts`，按规范化后的完整组合比较，
因此 `a` 和 `Ctrl+a` 不冲突，`Ctrl+s` 与固定保存动作冲突。
标签设置录制/保存、全局动作录制/恢复默认时阻止新增冲突，并列出动作或标签名称。
项目导入、模板加载、插件预置加载不因快捷键问题丢弃标注；常驻可见提示列出
冲突和非法绑定，并提供标签设置与动作设置入口。冲突键不执行任何候选，修正后
立即恢复；隐藏提示不改变执行、可用性或冲突规则。
输入框、遮罩、忙碌状态、输入法组合输入、长按重复均不能触发标签切换。

### 同步清单与输入输出样例

| 场景 | 输入 | 预期保存/输出 |
| --- | --- | --- |
| 旧单键项目 | `shortcut: "a"` | 读取、保存与重开仍为 `a` |
| 新组合项目 | `shortcut: "Ctrl+a"` | 项目与原生 JSON 保留 `Ctrl+a`，重开精确匹配 |
| 模板保存加载 | `shortcut: "Alt+Shift+1"` | 全局模板及项目快照均保留组合键 |
| 大小写与顺序 | `shift+CTRL+A` | 规范化为 `Ctrl+Shift+a` |
| 插件预置 | `shortcut: "1"` | 按 v1 Schema 加载，冲突可见，不丢弃标签 |
| 插件导出单键 | `shortcut: "a"` | v1 请求保留 `a` |
| 插件导出组合键 | `shortcut: "Ctrl+a"` | v1 请求省略 shortcut，项目内仍为 `Ctrl+a` |
| 固定动作冲突 | 标签 `Ctrl+s` | 阻止新绑定；历史冲突列出保存与标签名，提供改绑入口 |
| 无效历史数据 | `shortcut: "a+b"` | 数据可加载，绑定报错且不执行，允许清除/改绑 |

实现落点：`types/annotation.ts` 和 Rust 模型注释；共享快捷键解析、事件匹配及冲突
函数；标签设置；项目标签解析；`project-config.schema.json`；插件导出边界投影。
回归覆盖项目/原生 JSON/模板往返、插件 Schema 输入与投影输出、固定动作冲突、
Shift+数字键盘事件、遮罩与输入法门禁、长按忽略及载入冲突提示。
插件 Schema、Rust 插件校验和 conformance 基线保留并回归，证明旧边界未放宽。

## 其他软件的全局快捷键

Windows 或其他软件可能先截获组合键，应用收不到按键时无法录制或触发，也无法可靠枚举所有外部占用。不要以退出其他软件作为使用前提。选择未被占用的绑定；无法使用键盘时，点击侧栏「选择标签与样例图」仍可搜索并选择。应用内冲突检查只覆盖自身动作与标签，不代表系统级可用性保证。
