## 本轮桌面补验

使用临时项目 `label-tool-shortcut-acceptance`，包含两张 800×600 图片、50 个标签（长名称、单键和未绑定项）及一个原始矩形。所有绘制、改绑与导出均发生在该测试项目。

- 数量设置：800×600 内容窗口中，操作/标签上限分别设为 5/3，省略数量随当前未绑定标签更新；非法值 80 显示错误且不保存。标签总开关关闭后整块消失，重新开启保持条数。撤销逐项开关改变省略数量但不改变 Ctrl+Z 绑定。
- 撤销与选择：实际绘制矩形后 Ctrl+Z 移除、Ctrl+Y 恢复；选中矩形后 F2 搜索「标签4」、方向键移动到标签41、Enter 确认，再 Ctrl+Z 撤销。实际导出确认该矩形仍为原标签04。
- 画布：在四角分别绘制及拖动矩形，提示上下避让且不截获鼠标。操作提示设为 50，在小窗口中两端均覆盖鼠标时文字、背景与边框整体透明，离开后恢复。鼠标远离时即使提示与图片重叠也正常显示。缩放至 72% 后框与图片同步；D 切到无标注图片、改绑 F6 返回后原图片标注恢复。
- 标签面板：F2 打开、中文名称搜索、方向键及 Enter 确认链路通过；点击可见入口和鼠标选择通过。空结果有明确提示，再按 F2 取消保持当前标签。输入框内输入字母不会触发同名标签快捷键。
- 样例隔离：标签02使用刻意损坏的 PNG，标签04使用有效 PNG；前者仅在对应行显示预览失败，后者正常显示，缺图仍有占位。损坏样例对应标签仍能点击选择。标签管理页保存后刷新样例列表会报告损坏文件，但本次快捷键已保存到项目文件；该既有列表校验不影响选择面板的逐图隔离。
- 组合键：标签01录制 A、标签02录制 Ctrl+A，保存后分别触发；Ctrl+S 新绑定被阻止并列出固定保存动作与标签。用户用物理键盘确认 Shift+1 能录制为 `Shift+1`，保存后又确认能切换到标签04。
- 外部占用：Alt+1 被 PixPin 全局快捷键截获。遵照用户要求保持 PixPin 运行，不把退出其他软件当作前提；改绑 Alt+Q 后录制和触发通过，可见标签面板同样可用。界面与使用文档已说明外部占用、改绑和面板入口；不能承诺枚举全部系统级冲突。
- 按键注入边界：Computer Use 将 Shift+1 注入为 `key: "!", code: ""`，不能代表物理数字行按键；真实 Shift+1 结果以上述用户两次反馈为准，没有为适配工具改写按键解析规则。
- 实际导出：原生应用 Ctrl+S 写出的 JSON 经 PowerShell 标准 `ConvertFrom-Json` 解析通过，含 2 张图片、50 个标签和 6 个矩形；原始矩形仍为 `[100,100,200,100]`，普通图片 `frameIndex` 为 0，A / Ctrl+A / Alt+Q / Shift+1 绑定完整保留。
- 尺寸与重启：关闭并重新启动原生进程，通过一次性 `TAURI_CONFIG` 调试构建参数得到含标题栏的 1366×768 窗口（内容区 1364×738），仓库 `tauri.conf.json` 未修改。重开项目后 50 标签、6 个矩形、3 条标签提示、50 条操作上限、隐藏撤销提示及 F6 绑定保留，长名称不溢出。另已检查 1440×912 最大化窗口和 800×600 内容窗口。
- 减少动态效果：本次调试进程以 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--force-prefers-reduced-motion` 启动，实际 WebView2 进程命令行确认携带该参数；在原生窗口重复两端遮挡透明、离开恢复操作通过。该调试开关的语义见 [Chromium switches.cc](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/ui/gfx/switches.cc)，未改变系统动画设置。
- 用户物理输入补验：用户确认长按 F2 约 2 秒后面板保持打开、不反复开关；用中文输入法输入「标签」仅改变搜索结果，再按 F2 取消后当前标签仍为标签00。
- 总开关与恢复默认：关闭操作提示总开关后整块消失，重新开启保留设置。暂时隐藏「上一张图片」提示，省略数由 13 降到 12；恢复提示显示默认值后回到 13，该动作重新勾选，F6 绑定保持不变。操作/标签条数最终恢复为测试前的 8/8。

本轮补充界面说明后再次运行 typecheck、lint、760 项前端测试及 cargo clippy，全部通过；行覆盖率仍为 96.20%。临时键盘诊断代码已移除。收尾时已用正常配置重新构建，取消临时窗口尺寸和减少动态效果参数；上一张快捷键从验收用 F6 恢复为原来的 A，下一张仍为 D。
